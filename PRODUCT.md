# Product

## Product Name

MedShield-AI V5 Incident Response Console

## Positioning

A medical security incident response demo console for grassroots hospital data. The interface focuses on security event handling rather than first-screen metric display.

## Primary User Flow

1. User enters a hospital security console.
2. User selects a pending incident.
3. User analyzes the event.
4. System shows AI risk result and evidence.
5. User executes policy defense.
6. User verifies integrity.
7. User executes recovery or recovery evaluation.
8. User generates an audit record.
9. Formal metrics are shown later as evidence.

## Stack

Pure static HTML/CSS/JavaScript. No React, no npm, no external CDN.

## Data Contract

Read-only frontend artifacts under `public/data`. No backend recomputation. No mutation of formal JSON/CSV.
